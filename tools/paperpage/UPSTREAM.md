# Paperpage provenance

Derived from `maveryn/paperpage` at commit `746c795893b7544fa340f6ec2338fc998a68e977`.

Local adaptations: recursive LaTeX metadata extraction, TMLR author-block parsing,
PDFium fallback for PDF rendering, HTML escaping for Jinja templates, and a
Minerva presentation theme. Changes are
kept in this generator; `docs/` is regenerated rather than hand-edited.
